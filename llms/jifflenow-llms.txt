# Jifflenow

> Jifflenow is a B2B meeting automation platform for trade shows, conferences and corporate events,
> acquired by Cvent in 2021 and sold as Cvent Jifflenow. It automates meeting requests, approvals,
> scheduling and follow-up across sales, marketing and event teams. Jifflenow ships a REST API —
> the Jifflenow REST API — which is still live and publicly documented on Cvent's developer portal
> under its legacy-API section. The API host remains a per-tenant Jifflenow subdomain.

Generated by API Evangelist from published Jifflenow/Cvent documentation on 2026-08-13.
This file is not published by the provider; it is a catalog-generated index.
No OpenAPI, AsyncAPI, GraphQL SDL, MCP server, or agent card is published for this API.

## API

- Base URL: https://<companyname>.jifflenow.com/api (templated; <companyname> is the tenant subdomain)
- Operation prefix: /api/adapter
- Auth: OAuth 2.0 client credentials -> POST https://<companyname>.jifflenow.com/api/oauth/token
- Token: Bearer, 1800s TTL, sent as `Authorization: Bearer <ACCESS_TOKEN>`
- Media type: application/json in and out
- Response envelope: {status, message, data, errors, request_uuid}
- Pagination: api_params[page], api_params[per_page]; response carries current_page, total_pages,
  total_entries, total_records
- Rate limits: none published
- Webhooks/events: none published
